# Lore and references

The world's cosmology and the library of works, traditions, techniques and games The Roots draws on. Use it to name and design practices (items), projections (enemies), places and endgame. How to add to it is the project skill [`sotano-lore`](../../.claude/skills/sotano-lore/SKILL.md).

| Document | Contents |
|---|---|
| [SOURCES.md](SOURCES.md) | The reference library: every book, tradition, technique, therapy and game we draw on, with author, year, kind, naming status (public domain / generic concept / credit only / trademark caution), its key ideas and where it shows up in the game |
| [CONCEPTS.md](CONCEPTS.md) | The concept glossary: each idea (as above, so below; symbolic act; systemic belonging; impeccable word…) with its sources and its expressions in the game (mechanics, items, enemies, places) |
| [COSMOLOGY.md](COSMOLOGY.md) | The shape of the world: the depth and the surface as mirrors (the Hermetic principle of correspondence), the seven Hermetic principles mapped to systems, how the deepest point and the surface connect in the endgame, and other maps of the same world (the Tree of Life, the I Ching's trigrams and hexagrams, the Kybalion's transmutation and rhythm) |

How this section relates to the rest:

- [../design/STORY.md](../design/STORY.md) is the **player-facing story and the naming rules**; it wins on names and tone.
- This section is the **source of truth for references and concepts**: every `inspiredBy` in an item must point at an entry in SOURCES.md, and every new mechanic with a meaning should have a concept in CONCEPTS.md.
