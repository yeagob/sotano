# The four paths

Up: [built story](README.md)

Every practice moves the person along one or more paths. The paths are how a practice is filed, how it counts toward a state of being, and how the HUD names it. The four paths as built:

| Path | Glyph | What it develops | Practices (first path) |
|---|---|---|---|
| **Body** | ■ | Presence, energy, nervous-system regulation | 7 (folder: [body](../practices/body/README.md)) |
| **Mind** | ◆ | Clarity, focus, belief | 16 (folder: [mind](../practices/mind/README.md)) |
| **Emotion** | ● | Feeling instead of avoiding; release; compassion | 12 (folder: [emotion](../practices/emotion/README.md)) |
| **Will** | ▲ | Consistency, discipline, small steps compounding | 10 (folder: [will](../practices/will/README.md)) |

The counts are the first path of each practice; several practices carry a second path, so the paths overlap. The full list with the second paths is in each folder's README.

## How the tag is used

- Every practice in the code carries one or more path tags. The first one decides its folder in the documents. The tags are the game's way to count: three practices with the same tag make that path's state of being ([states of being](../practices/states-of-being/README.md)).
- A practice with several tags counts for each of them. Satori carries all four, so it adds one to every state.
- The tags are labels. They do not change a practice's effect; the effect is the stat or the event it has.
- Mechanical tags that are not paths (such as blocks, explosive, contact, weapon, electric, fire, movement, mining, intent) describe what a practice touches. They are not part of the path count.

## How the path is shown

- The HUD shows a path chip next to a practice's name: the path's colour, always with its glyph and its word, so the colour is never the only signal.
- Each path has a colour family in the palette (a base and a glow). A practice is coloured by its first path's glow.
- The glyphs are the path's identity on the screen. The art record lists them as ■ body, ● emotion, ◆ mind and ▲ will.

## What the paths are not

The paths are not a character class. The protagonist does not pick one at the start, and no path is better than the others. The state of being is a reward for focus, not a grade.
