# The sky (built)

Up: [built](../README.md) · the parts of the sky realm that are in the code now. The realm as a whole (the sky tree, the animals, Totality and the Spiked Entity) is not built yet: what is still to come is in [not-built/sky](../../not-built/sky/README.md).

The sky is the second world of a run, above the built tree. The parts documented here are the hindrances its animals use against the player. They share one rule: a hindrance never takes the player's health (nothing in the sky does), so a hindrance only pushes, slows or holds the player, and its worst outcome is a fall to a lower platform.
