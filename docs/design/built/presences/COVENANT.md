# The Covenant (built)

Status: **built** (issue #149; changed by the owner's rulings on #228: the Light at the crown, D4, and the Thread as an item, D10). The record, the four pieces, the closed-set rule and the set effect are in the code. The closed-set reading and the set effect's wording are decided by agent, pending owner ruling (see [not-built/presences/COVENANT.md](../../not-built/presences/COVENANT.md)).

## What is built

- **Four pieces, one source each.** The Mender gives the Thread (dropped as an item after a Give on its card, kept when it is picked up), the Elder gives the Page (on its choice card, with its lesson), and the Witness gives the Seal (after a Take on its card). The Light is kept in the crown of the giant tree, in a run that has heard a Listener's Lesson (owner, #228, D4), see [LISTENER.md](LISTENER.md#the-lesson).
- **A run record.** The pieces held are kept for the run only, in the order given, and reset at a new run with the codex. Nothing is kept in the profile save, and no randomness is read: the same exchanges give the same record.
- **Promised.** The Page, the Seal and the Light are a record, so nothing can take one. The Thread is the Mender's Thread, an inventory item (owner, #228, D10, see [MENDER.md](MENDER.md#the-menders-thread-owner-228-d10)), and it is promised: no capture, toll or other rule takes it, so the record never gives a piece back. Giving a piece twice changes nothing.
- **The closed set (decided by agent, pending owner ruling).** The owner's word "cierre" is read as a closed set, and it is a rule in code: exactly four pieces, each with exactly one source (`PIECE_SOURCE`, frozen), given once, never taken back, and a complete record that no source changes again. No shop, drop, other presence, sandbox or save gives a piece; the Listener's plain exchange gives none, and a Thread granted by the debug tools is an item but no piece. Reason: it is the plainest reading of the word and of the design's "no other source gives them", and it keeps the gift promise by construction.
- **The set effect.** Holding all four is the Covenant complete: a toast says so once, and from then on every presence's exchange card ends with a line that it remembers the player. It gives no stat.
- **In the inventory (decided by agent, pending owner ruling).** Each piece held is a labelled tile under the synergies: its name, the presence it came from, "promised", and a gold seam along the bottom edge (art ledger, DECISIONS.md §14.2). Nothing shows before the first piece. The Thread's tile stays in the list as the record of the piece; the item itself is in the practices, with its own icon. Reason: GIFTS.md asks for labels and the seam on gifts.
- **Code.** `src/content/presences/covenant.ts`, read by the game in `keepCovenantPiece`, `reachCrown` and `exchangeLines`; the Thread in `src/content/presences/thread.ts`; the labels in `renderInventory` (`src/game/hud.ts`). Tested in `tests/covenant.test.ts`, `tests/presences-lesson.test.ts` and `tests/menders-thread.test.ts`.
