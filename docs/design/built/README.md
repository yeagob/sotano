# Built

Up: [The design document](../README.md) · what exists in The Roots today. Every claim in this branch can be checked in the code or in play. When a feature is built, its text moves here from [not-built](../not-built/README.md) in the same commit.

Each section below is a folder with its own README. Read one section's folder to get the whole of that part.

| Section | What it covers |
|---|---|
| [player](player/README.md) | The one body you control: walking, jumping, swimming, hearts, death, the hand, the controls |

| [blocks](blocks/README.md) | The matter of the world: tiers, hit points, armour, loose cubes, carrying, kicking, throwing and bombs |
| [elements](elements/README.md) | Water, lava, fire, ice and wood, and what happens when they meet |
| [levels](levels/README.md) | The thirteen places from the roots to heaven, the rooms inside them, and the giant tree |
| [chests](chests/README.md) | Chests, keys and the key economy |
| [laboratory](laboratory/README.md) | The alembic on floors 2, 4, 6 and 8: feeding it, brewing with intention, three brews per run, eight recipes and their durations |
| [projections](projections/README.md) | The patterns that block intention: forty projection entries, sixteen fully built and twenty-four partly built |
| [creatures](creatures/README.md) | The living things of the depths: they wander, hide and heal, and do not fight |
| [presences](presences/README.md) | The archetypes you can talk to: the Listener and the Boundary |
| [encounters](encounters/README.md) | How a fight begins: the seal, the omens, the spawns, the waves, the attacks and how beings move and choose targets |
| [bosses](bosses/README.md) | The fourteen bosses, their fight flow, and the arenas that change the world |
| [practices](practices/README.md) | The practices (items), the synergies and the four states of being |
| [story](story/README.md) | The premise, the metaphor, the naming rules and the in-game vocabulary |
| [feel](feel/README.md) | The HUD, the sound, the feedback, the art and the languages as built |
