# Star-mite

Built. Floors 1 to 5, as ambient life. Code: `src/content/creatures/star-mite.ts`.

A Star-mite is a tiny dark mite with three glowing points, set in a triangle on its back, like a constellation. It stands for joining what is apart. It answers only positive intentions.

- **Pattern:** joining what is apart.
- **Health:** 2.
- **Answers to:** positive intentions only.

## Movement and character

- Drifts about two blocks above the floor, between two and a half and six blocks from the player.
- Three glowing points in a triangle, which read as a constellation.
- One or two appear per floor from 1 to 5.

## What the player can do

- Heal it: a positive intention heals it if it is hurt.
- Ignore it: a negative intention passes through it.
- Watch the three points. They are the one place in the game where the constellation shape is visible in a creature.

## Open questions

- **Which tree.** Like the Leafling, the design places it on the Tree and the build places it on the underground floors 1 to 5 (the level the code calls the tree).
- **Joining.** The design has the Star-mite join the player's teleport doors on the star map. Not built: see [Teleport doors](../../not-built/creatures/TELEPORT-DOORS.md).
