# Encounters (built)

An encounter is the way a fight begins, unfolds and ends in a room: the doors shut, the projections announce themselves before they exist, they come in waves, they attack, move and find the player. The encounter layer is what the player feels first in every room, so its rules are shared by every projection and boss. This folder holds the built rules, each in its own document, and the two basic ideas they all depend on: the kinds of beings and polarity.

| Document | Contents |
|---|---|
| [KINDS-OF-BEINGS.md](KINDS-OF-BEINGS.md) | The three kinds of beings: projections, creatures and presences |
| [POLARITY.md](POLARITY.md) | Good and bad intentions and what each does to each kind of being |
| [SEAL-AND-OMENS.md](SEAL-AND-OMENS.md) | The doors that shut, the omen every projection is announced by, and the clear |
| [SPAWNS-AND-WAVES.md](SPAWNS-AND-WAVES.md) | Where projections rise, how waves follow one another, and the breath between them |
| [CHALLENGE-ROOMS.md](CHALLENGE-ROOMS.md) | The challenge room: three harder waves, and a reward for each |
| [ATTACKS.md](ATTACKS.md) | The attack shapes and the telegraph every attack gives before it lands |
| [MOVEMENT.md](MOVEMENT.md) | The movement behaviours projections, creatures and bosses use |
| [TARGETING.md](TARGETING.md) | Whom a being chooses to attack, and when it changes its mind |

Bosses have their own folder, [bosses](../bosses/README.md), which uses these rules; the moves a boss makes are in its fight flow.

Shared numbers in this folder are the code's values, rounded for reading. A number here that disagrees with the code is wrong, and the code wins.
