## What it means

Making something changes the maker: four connected blocks you place in a room can heal you.

## What it does

Placing 4 connected blocks in the same room heals one heart. Once per room.

## Stats and events

- heals: one heart
- when a block is placed: counts the connected placed blocks in the room
- when a room is entered: the count starts over
- when a floor is entered: the once-per-room memory is cleared
