# Intentions (built)

Intentions are the player's shot. The player does not fire tears: they cast intentions, small orbs of will that fly, fall and hit. Each has the same base stats, one of two polarities, and a set of effects that items can add. A practice can also replace the intention with a weapon. This folder describes what exists in the game today; the planned parts are in [not-built/intentions](../../not-built/intentions/README.md).
