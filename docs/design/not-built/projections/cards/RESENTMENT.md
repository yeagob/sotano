Status: proposal. The card is the design. The built side of this projection is in [built/projections/RESENTMENT.md](../../../built/projections/RESENTMENT.md), and each card field that is not in the code stays here.

Zone II · The Flooded Rooms (floors 3–4).

**Line · pattern · need.** "I won't forget." · the grudge · to not be hurt again

**Path · size · husk · glyph.** Emotion · medium · dark · `ꟷ` with a hook (a held thread)
