# Projection cards (not built)

The design card of each projection: its line, pattern, need, path, size, husk, glyph, behaviour, signature, how it lives with the elements, its release and its touching moment. The cards are the bestiary's design of 2026-10-27, written from the owner's brief. The built side of each projection, what the code does, is in [built/projections](../../../built/projections/README.md); each card names its built document.

Each card follows the art guide's method (ART-GUIDE §8.1): the line in the player's voice, the pattern, the need underneath, the path whose shadow it is, size and value class, a unique glyph, the behaviour and its one signature attack, how it lives with the elements, its release, and the touching moment. Health is base health on floor 1 scale (× the table in [SCALING](../SCALING.md)). "Mechanic nod" names the game mechanic it rhymes with, for us only: in the game nothing is named after another game.

Glyphs in use are unique: `?` Doubt, `Γ` the Lectern, `✳` Panic, and those on each card. Lineage cards list their forms in order (I, II, III).

Procrastination's two splits (Procrastination B and C) are built as projections of their own; their design is the Procrastination card, which describes the splitting.

Status: proposal for each card. Each document carries its own status line.
