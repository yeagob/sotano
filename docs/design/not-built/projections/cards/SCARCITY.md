# Scarcity: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/SCARCITY.md](../../../built/projections/SCARCITY.md), and each card field that is not in the code stays here.

Zone II · The Flooded Rooms (floors 3–4).

**Line · pattern · need.** "There won't be enough." · hoarding · to be safe

**Path · size · husk · glyph.** Will · small · dark · `◒` (a pouch)

**Behaviour and signature.** Runs for **pickups**: keys, bombs, hearts on the floor; steals them and flees, and if it reaches a wall it burrows a pocket and hides them. **Releasing it gives back everything, plus one**

**Release · touching moment.** The pouch turns out and everything rolls out, plus one more · There was always enough; it just couldn't see it

**Mechanic nod.** Isaac's thieving greed enemies; the fourth circle's hoarders
