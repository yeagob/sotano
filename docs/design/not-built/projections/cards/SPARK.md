# Spark: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/SPARK.md](../../../built/projections/SPARK.md), and each card field that is not in the code stays here.

Zone IV · The Furnace (floors 7–8).

**Line · pattern · need.** "Is that—? What was—?" · restlessness, always on edge · to never be caught off guard

**Path · size · husk · glyph.** Body · small · dark · `ϟ`

**Behaviour and signature.** Lives on conductive blocks (ore, metal). **Jumps between them**, and two Sparks link with an **arc across the room** (a Line) for 2 s: a wall you can't cross while it's live. Break the blocks it lands on to ground it

**Release · touching moment.** It grounds, one last crackle, and goes still · It stayed on edge so nothing could surprise it; still, it finally rests

**Mechanic nod.** Noita's electric creatures
