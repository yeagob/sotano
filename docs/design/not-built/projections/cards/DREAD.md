# Dread: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/DREAD.md](../../../built/projections/DREAD.md), and each card field that is not in the code stays here.

Lineage: Panic → Alarm → Dread (Will).

Form on this card: III · Dread.

**Line.** "Something *will* go wrong."

**Floors.** 6–9

**Size · husk · glyph.** Medium · dark · `◎` (a ring within a ring)

**Health · cost.** 40 · 3

**Behaviour.** Never bursts. It hangs back and **pulses shockwaves** (rings along the floor) every 3 s, which you jump over; each ring cracks soft floor

**Signature.** **Sweep**: rings across the whole room

**Elements.** In water its rings become ripples that don't hurt; in fire they grow

**Release.** Its rings slow and stop; the last one is a still circle on the floor that fades

**Touching moment.** It was waiting for the bad thing so it would never be surprised again; released, nothing happens, and that's the point
