# Perfectionism: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/PERFECTIONISM.md](../../../built/projections/PERFECTIONISM.md), and each card field that is not in the code stays here.

Lineage: Perfectionism → Not Yet (Body).

Form on this card: II · Perfectionism.

**Line.** "It has to be perfect."

**Floors.** 3–6

**Size · husk · glyph.** Tall · pale shell, dark core · `⬡` (a shell around a dot)

**Health · cost.** Shell 6 plates × 4, core 14 · 3

**Behaviour.** Takes almost no damage until you **break its plates** (each plate is a real voxel on its body, breakable by intentions, kicked cubes, bombs)

**Signature.** Touch (slow, heavy)

**Release.** Its broken plates come back with **gold seams** (the only projection that releases into gold: the seam is yours, you broke it)

**Touching moment.** Under the shell there was a small rough figure that wanted to be loved without the shell
