# Sulk: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/SULK.md](../../../built/projections/SULK.md), and each card field that is not in the code stays here.

Zone III · The Ledger Halls (floors 5–6).

**Line · pattern · need.** "Fine." · sullenness, anger turned inward · to be noticed without asking

**Path · size · husk · glyph.** Emotion · medium · dark · `▁` with two eyes

**Behaviour and signature.** A **swimmer in mud**: lies under the marsh with only its eyes showing. When you pass within 3 blocks it **erupts** (a Burst of mud that slows), then sinks back. It never chases

**Release · touching moment.** It surfaces and stays up, mud running off it · It wanted someone to notice it was hurt, without having to say so

**Mechanic nod.** The fifth circle's marsh
