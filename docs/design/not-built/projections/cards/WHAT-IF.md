# What If: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/WHAT-IF.md](../../../built/projections/WHAT-IF.md), and each card field that is not in the code stays here.

Zone V · The Frozen Bottom (floor 9).

**Line · pattern · need.** "What if I had…" · regret · to undo it

**Path · size · husk · glyph.** Mind · medium · translucent dark · `↺`

**Behaviour and signature.** A **phaser** that rises from the shards of projections you've released in the room and **replays their last move** (a ghost of a charge, a lob, a burst), once each. It passes slowly through blocks

**Release · touching moment.** It stops replaying and lets the last shard rise · It kept the past alive so it could be done differently; it can't, and that is the release

**Mechanic nod.** Noita's resurrecting necromancers
