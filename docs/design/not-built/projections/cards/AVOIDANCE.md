# Avoidance: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/AVOIDANCE.md](../../../built/projections/AVOIDANCE.md), and each card field that is not in the code stays here.

Zone I · The Cellar of Habits (floors 1–2).

**Line · pattern · need.** "Not now." · looking away from what hurts · to not feel it

**Path · size · husk · glyph.** Emotion · small · dark · `◘` (a block with eyes)

**Behaviour and signature.** **Hides inside a block** of the room (spawn kind "block"): looks like the host material except for two dim eyes. Peeks out, throws a small cube (Lob), and hides. Only hittable while peeking, **or if you break its block**

**Release · touching moment.** Its block opens like a shell and it sits outside it · It never wanted to hurt you; it wanted not to be seen hurting

**Mechanic nod.** Isaac's hiding hosts
