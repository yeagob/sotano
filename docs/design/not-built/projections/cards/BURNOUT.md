# Burnout: the card

Status: proposal. The card is the design. The built side of this projection is in [built/projections/BURNOUT.md](../../../built/projections/BURNOUT.md), and each card field that is not in the code stays here.

Zone IV · The Furnace (floors 7–8).

**Line · pattern · need.** "I can't stop." · running past empty · to be enough

**Path · size · husk · glyph.** Will · medium · dark · `⇶`

**Behaviour and signature.** Born from fire (spawn kind "element source"). **Accelerates** the whole fight: faster every second, leaving short-lived fire on the floor. After 8 s it **collapses, exhausted** (3 s, takes ×2 damage), then starts again, slower each time. The fight is **outlasting** it, not racing it

**Release · touching moment.** It sits down by a cold flame and the flame goes out · It never wanted to win; it wanted permission to stop
