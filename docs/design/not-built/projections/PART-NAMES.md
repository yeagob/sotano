# Part names and what parts are for

Status: proposal. The chances, the way parts drop and the icons are built ([PARTS](../../built/projections/PARTS.md)). The names below are the design's names for them; the built names go through the localisation rule below.

## The rule

Every projection names its four parts after its own pattern, so a part tells you what it was. The rest are named when they are built, with the same rule: the part's noun comes from the creature's own body or pattern, never from another game. Names go through [`sotano-i18n`](../../../../.claude/skills/sotano-i18n/SKILL.md) in both languages.

## Where parts matter (proposal)

Agreements ([AGREEMENTS](../presences/AGREEMENTS.md)) ask for parts by name, so a part in the pack is a clue about the floor it came from. The farming room, the Compost, is designed in [COMPOST](../encounters/COMPOST.md). Until those exist, parts have no use: a shop where they can be traded is a pending task ([SHOP](../player/SHOP.md)). The owner's answer is the Alembic in a laboratory, which brews parts into potions with no shop ([ALEMBIC](../stations/ALEMBIC.md)).
