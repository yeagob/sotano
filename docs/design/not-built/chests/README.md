# Chests and keys (not built)

Up: [not-built](../README.md) · what the chest and key design says that the code does not do, or does differently.

The built chests and keys are in [built/chests](../../built/chests/README.md). This folder holds what the owner's text still asks for and the build does not do: chests on the roots, keys that change only through chests, the rewards of a cleared room, a few chest variants that were only ideas, and the chest's interface. Where the build and the design disagree, the disagreement is written here with both readings, and the owner has to choose.

Status lines use the design tree's words: `decided`, `proposal`, `idea`. None of these changes the build until the owner rules on it and it is built.

|---|---|---|
| [ROOT-CHESTS.md](ROOT-CHESTS.md) | proposal, open | Room chests on the roots: the design says yes, the build says no |
| [KEY-SOURCES.md](KEY-SOURCES.md) | proposal, open | Keys change only through chests: the design says so, the build also spends and gives keys elsewhere |

| [CHEST-VARIANTS.md](CHEST-VARIANTS.md) | idea | Mimic chests, chests that need a state of being, chests that move while you look away |
