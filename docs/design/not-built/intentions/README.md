## Open questions shared by the folder

1. **The look of an intention.** The design says the name is final and the visual language is still open; the first prototype used pale blue orbs ([DESIGN.md, section 13, question 3](../README.md)). The built look is a gold shell with a white-hot core for a positive intention, and a charred ash shell with a dimmer core for a negative one ([built/intentions/FLIGHT.md](../../built/intentions/FLIGHT.md)), as the art ledger records it (`docs/art/DECISIONS.md`, section 7.1). Is that the look the owner wants, or does the owner want to reopen it?
2. **Items that give an intention a new element.** The design sketches fire, explosive and leaden intentions as practices ([DESIGN.md, section 10](../practices/README.md)). Their names and effects belong to the practices section, not to this folder; this folder keeps the question of how each one changes the shot's own properties.
