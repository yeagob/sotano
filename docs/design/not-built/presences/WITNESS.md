# The Witness

Status: **proposal**. No identifier in the code.

A dweller of seeing without judging. It waits in the silence below the ninth floor, the last conversation before the loop back to heaven. It gives no reward but the conversation itself: a Reading of the run.

## What the design asks

- **Reading.** The Witness reads the player's run: their hexagram (a lore element to check against the lore library), the patterns they released, and the ones that held them.
- **Agreement.** It asks for one part of each pattern the player released. This is the last agreement of the run (see [Agreements](AGREEMENTS.md)).
- **Covenant.** It gives the Seal, one of the four pieces of the Covenant (see [Covenant](COVENANT.md)).
- **Shape.** Abstract, never a human figure.

## Open questions

- **The Silence.** The place below floor 9 is not built. The loop to heaven is a milestone (L4).
- **The hexagram.** A reading by hexagram needs a source check before any text is written (see the [lore library](../../../lore/README.md)).
- **Parts.** A part of each pattern is only possible if the player has released that pattern. A run that released none needs a line of its own.
