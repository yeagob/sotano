# The Covenant

Status: **proposal**. The set effect is decided (every Presence remembers the player in the run, owner 2026-10-27).

The Covenant is a closed set of four pieces, given only by four presences. No other source gives them: no shop, no drop, no other presence. Each piece comes from one presence, and each has a meaning.

| Piece | From | Its meaning |
|---|---|---|
| Thread | The Mender | Repair that holds |
| Page | The Elder | The rule the player chose to keep |
| Seal | The Witness | Seeing and keeping |
| Light | The Listener, after its last Lesson | What was heard |

Holding all four completes the Covenant. Its set effect: every Presence remembers the player in the run.

## Open questions

- **Dependencies.** Three of the four come from presences that are not built (the Mender, the Elder and the Witness). The Listener's Lesson is not built either. The Covenant cannot be built until those exist.
- **Closed set.** The owner's word "cierre" is read as a closed set. That reading (the owner's answer l in the design's section 13) is still to be confirmed.
- **Promise.** Each piece is a gift with the promised trait (see [Gifts](GIFTS.md)): it cannot be dropped, destroyed or stolen.
- **The set effect.** "Every Presence remembers you in the run" needs the presences to remember, which needs the run state to hold them. Decide where.
