# The Covenant

Status: **built** (issue #149, see [built/presences/COVENANT.md](../../built/presences/COVENANT.md)). The set effect is decided (owner 2026-10-27). The record, the four pieces, the closed-set rule and the set effect are built; the closed-set reading is decided by agent, pending owner ruling (README, D3). The owner ruled the Light's place (the crown of the tree, D4) and the Thread's form (an item, D10) on #228. What remains here is the wording.

The Covenant is a closed set of four pieces, given only by four presences. No other source gives them: no shop, no drop, no other presence. Each piece comes from one presence, and each has a meaning.

| Piece | From | Its meaning | Status |
|---|---|---|---|
| Thread | The Mender | Repair that holds | built: an item dropped on a Give (D10) |
| Page | The Elder | The rule the player chose to keep | built: given with the lesson |
| Seal | The Witness | Seeing and keeping | built: given on a Take |
| Light | The crown of the great tree, after a Listener's Lesson | What was heard | built: kept in the crown (D4) |

Holding all four completes the Covenant. Its set effect: every Presence remembers the player in the run.

## Decided by the build (proposed, pending owner ruling)

- **The record is per run.** It is kept with the codex and reset at a new run. It is not in the profile save, so memory across runs (MEMORY.md) stays knowledge and the Covenant stays a run rule.
- **Three pieces are a record, the Thread is an item.** The Page, the Seal and the Light cannot be dropped, destroyed or stolen. The Thread is the Mender's Thread, an inventory item by the owner's ruling (#228, D10), promised: no rule takes it. The labels and the gold seam are built (DECISIONS.md §14.2).
- **The set effect is a line.** Once all four are held, every presence's exchange card ends with one line that it remembers the player. It gives no stat and changes no item.
- **No randomness.** A piece is given by an exchange that already has its outcome, so the record moves no random stream and needs no generation version.

## Open questions

- **Wording.** "Every Presence remembers you" is said in one line on each card. The owner has not approved the line's text (en: "You have kept the Covenant. I remember you now."; es: "Has guardado el Pacto. Ahora te recuerdo.").
- **Closed set.** Decided by agent, pending owner ruling (README, D3). The Light's place was ruled by the owner (D4).
