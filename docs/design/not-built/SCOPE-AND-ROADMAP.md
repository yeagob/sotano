# Prototype scope and roadmap

Status: decided (the prototype scope of the design draft, v0.2). The progress marks on each item are a snapshot from the first build and are history: the status of each feature is in its own document.

The working title is The Roots: an open-source prototype for the browser (WebGL), deployed on Vercel.

The minimum that proves the idea: if it is fun, the prototype grows to four floors, bosses and secrets.

1. First-person controller with hands, intentions that drop. **(M0 ✔)**
2. A breakable 13×7 room, with blocks that fall with physics, can be picked up, kicked and placed. **(M0 ✔)**
3. A full generated floor (8–11 rooms) with doors, keys, bombs, treasure room and boss. **(M1: done except bombs and the boss itself)**
4. 3 enemies (zombie, skeleton, exploder) and 1 block-built boss.
5. 10–15 items with real synergies between them. **(M1: 11 items, 3 synergies)**
6. Going down to floor 2 by trapdoor **or** by digging, with floor streaming. **(M1: trapdoor only; each floor replaces the last)**
7. Climbing back up by digging and placing blocks until the surface (even if the surface is an empty meadow).

Where the items now are: the enemies of the first list are superseded ([ORIGINAL-BRIEF](projections/ORIGINAL-BRIEF.md)); the climb is [ROUTE-FROM-ROOTS](levels/ROUTE-FROM-ROOTS.md); the floor streaming is in [ROUTE-FROM-ROOTS](levels/ROUTE-FROM-ROOTS.md) too, under revisited floors.
