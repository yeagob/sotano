# Levels (not built)

Up: [not-built](../README.md) · what the level design still says that the code does not do, or does differently.

The built levels are in [built/levels](../../built/levels/README.md). This folder holds the rest: the paths of the Tree that the design wants to vary, the three upper maps that the design calls floors (trunk, branches and leaves) while the build has the tree as stories, the climb from the roots to the surface, the constellations' place, the ending of a run, the silence-and-heaven mechanism, the toll on the fifth floor, and the cavern scenery proposed for the first five floors. Each document has a status line and its open questions. None of them is built by default: a feature moves to the built branch in the same change that ships it.
