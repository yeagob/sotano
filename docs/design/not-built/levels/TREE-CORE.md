# The tree's core and branches: what is still open

Up: [not-built levels](README.md) · Status: built in part (issues #328, #317 and #329). This document keeps only what is still open.

## What is built

- **The core (#328)** is the whole climb inside the trunk, from the Roots hall to the top of the trunk. The four stories (roots, rings, galleries, hollows) stay as the frame. Each spiral stair is a broken, parkour climb: broken treads and leaps to jump, plugs of earth to dig, a waterfall to swim up in the galleries, and a gap to rebuild on every story. There is one climb, with the halls as detours. Every section is passable with the base body plus digging and placing blocks. See [TRUNK](../../built/levels/giant-tree/TRUNK.md).
- **The gaps (#317)** are the core's zones where you must place blocks: 5, 6, 7 and 8 missing steps, one block laid per step, 26 in all. A normal jump cannot cross one. Each story has one. The Leaves are reached on foot after the climb, and a player with no items gets through by building ([TRUNK](../../built/levels/giant-tree/TRUNK.md), the gap table).
- **The six branches (#329)** each hold a platform course with its own mechanic: sideways movers, lifts, platforms that give way, alternating pairs, a rhythm, and beams with single cubes. All start from the trunk's top story, in free order, with fixed layouts. Each ends in its ball of leaves with a practice at the centre. All six in one run give the achievement `tree.branches.all` and the Camina Despacio hook. There are no decorative limbs. See [BRANCHES](../../built/levels/giant-tree/BRANCHES.md).
