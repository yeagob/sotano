# Field notes

Status: idea. Index: [stations](README.md).

Field notes are a lectern with a book. Every reaction the player discovers is drawn there, and the book keeps it across runs. It is meta-progression as knowledge, never power.

## Design

- **What it does:** each discovered reaction (from [EXPERIMENT-TABLE](EXPERIMENT-TABLE.md)) is drawn in the book. The book is kept across runs.
- **Verb:** read the book at the lectern. Reading is free.
- **Meaning:** knowledge, not power. The player's understanding grows across attempts.
- **Tier:** T3, because knowledge crosses runs.
- **Parallel:** the codex that potions keep across runs ([potions README](../practices/potions/README.md)) is the same idea.
