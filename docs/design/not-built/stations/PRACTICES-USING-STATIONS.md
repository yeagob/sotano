# Practices that could use stations

Status: idea. Practice ideas, not built, not yet through [sotano-items](../../../../.claude/skills/sotano-items/SKILL.md). Names are generic technique names, and any work they credit goes in the sources list ([lore](../../../lore/SOURCES.md)). Index: [stations](README.md).

Each practice is a generic name, as the naming rules require ([STORY](README.md)). The effect is a proposal.

| Practice idea | Path | Effect |
|---|---|---|
| Alchemy | Mind | Furnaces and the experiment table give a better result one time in three |
| Mindful eating | Body, Emotion | Meals heal half a heart more and give their state for twice as long |
| Gardening | Body, Will | Planters grow at once; vines grow two blocks higher |
| Letting go | Emotion | Everything burned in a pyre gives a mote of luck |
| Shadow integration | Emotion, Mind | Husks drop from every released projection; cooked husks heal fully |
| Craftsmanship | Will | One hit of intention on the anvil makes two tools |

## Open questions

1. "Shadow integration" uses Jung's word. The brainstorm asks that Jung is credited only, not used as the name. The owner and [sotano-lore](../../../../.claude/skills/sotano-lore/SKILL.md) must confirm the name.
2. Every practice needs a path tag ([sotano-docs](../../../../.claude/skills/sotano-docs/SKILL.md)); the brainstorm lists two paths for some, which the owner must choose between.
3. The alchemy practice's "one time in three" is a random decision: it takes its own stream ([RNG](../../../architecture/RNG.md)).
