# Pump

Status: idea. Index: [stations](README.md).

A pump raises water. Effort lifts emotion to where it is needed.

## Design

- **What it does:** kicked, it raises water one block into a basin above. Each kick is one block.
- **Verb:** kick the handle. Water rises one block per kick.
- **Meaning:** effort lifts emotion where it is needed.
- **Vertical use:** it fills raised basins, which puts out fire on a gallery.
- **Tier:** T2 (it holds water and moves it).
