# The weighing chair

Status: idea. Index: [stations](README.md). The family rules for instruments of self-punishment are in [README](README.md), rule 7.

The weighing chair stands for measuring your worth. The player sits in it with the use key, and it shows how many hearts the player "weighs". Projections nearby turn to look.

## Design

- **What it does:** sitting shows how many hearts the player has.
- **Verb:** sit (use key).
- **Meaning:** measuring worth. The chair is the easiest instrument to misread as a verdict on the player.
- **Dismantled:** brass.
- **Tier:** not set in STATIONS.

## Open questions

1. The chair's readout is a number of hearts. Is it a verdict on the player, which the respect rule forbids, or only a reading? The owner decides.
2. Projections turning to look is a behaviour. Which projection, and does it attack?
3. The use key is not fixed (see [README](README.md), rule 3).
