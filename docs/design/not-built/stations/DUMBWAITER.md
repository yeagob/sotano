# Dumbwaiter

Status: idea. Needs an explicit exception to the band rule and a three-party review. Index: [stations](README.md).

A dumbwaiter is a small box in a one-by-one shaft between floors. The player loads it and pulls the cord; it rises or drops to the next floor's twin hatch. It brings what was found below up to daily life.

## Design

- **What it does:** carries cubes between floors through a shaft.
- **Verb:** load the box, pull the cord.
- **Meaning:** integration. What you found below is brought up to daily life.
- **Tier:** T3. It is the one zone that crosses floors on purpose.
