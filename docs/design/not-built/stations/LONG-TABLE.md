# The long table

Status: idea. Index: [stations](README.md).

A long table is the kitchen's place of sharing. The player places up to four meals on it and eats together, and the room's lamp lights. It is a small wink at belonging.

## Design

- **What it does:** up to four meals on the table give one bigger effect for the set. The room's lamp lights.
- **Verb:** place the meals on the table one by one. Eating from the set is a single act with the use key.
- **Meaning:** sharing and belonging.
- **Tone:** food never punishes. There is no "you ate too much" debuff.
- **Tier:** T1 (a surface with one reaction).

## Open questions
