# Larder

Status: idea. Index: [stations](README.md).

A larder stores ingredients for the run. What the player leaves in it too long rots into mud. What is put off spoils.

## Design

- **What it does:** keeps ingredients for the run. A cube left too long rots into mud.
- **Verb:** place a cube on a shelf. Taking it back is the same as picking up any cube.
- **Meaning:** what you put off spoils. It is the natural home for the projection Procrastination (not yet designed; see [PROJECTIONS-AT-STATIONS](PROJECTIONS-AT-STATIONS.md)).
- **Tier:** T2 (a timer per stored cube).

## Open questions

1. How long does a cube keep: seconds, rooms or floors? Potions count rooms cleared, so a larder could match them.
2. Does rotting into mud create a hazard, or only the mud?
3. Does a larder keep cubes across floors? If so, see [VERTICALITY](VERTICALITY.md) for the floor-crossing rule.
