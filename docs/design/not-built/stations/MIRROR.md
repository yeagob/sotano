# Mirror

Status: idea. Index: [stations](README.md).

A mirror reflects intentions. On floor circle 8 (fraud and illusion), some mirrors show a room that is not there. Seeing yourself, and illusion.

## Design

- **What it does:** reflects an intention. Some mirrors on circle 8 show a room that does not exist.
- **Verb:** hit the mirror with an intention; it returns the intention at an angle.
- **Meaning:** seeing yourself; illusion.
- **Tier:** T1 (a reflective block).
