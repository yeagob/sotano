# The Pedestal (Tree floor L2)

Status: **idea**. The Tree is not built (milestone L5). This is a direction for the owner to design with the Tree.

The branches mirror the Ledger Halls, where old rules are set in stone. Their patterns are pride and being above others.

- **Mirror:** the Ledger Halls (floors 5 and 6).

- **Boss (idea):** the Pedestal, which lifts the player up and dares them to look down.
