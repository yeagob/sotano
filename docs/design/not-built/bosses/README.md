# Bosses (not built)

Status: **mixed**: decided for the Threshold Guardian's light route and the Shadow's keystone, proposal for the rest, idea for the Tree's bosses. Each document carries its own line.

What the design asks for the bosses that the build does not have yet. Every boss in the game has a built document in [built/bosses](../../built/bosses/README.md); the documents here hold only the parts of a boss's design that are not in the code, and the parts that are not in any boss at all. Each document has a status line: `decided` (the owner decided it, not built), `proposal` (designed, awaiting the owner or a build) or `idea` (a direction, no commitment). The shared rule for a boss's body and release is in [Voxel bodies](VOXEL-BODIES.md).
