# The Many Faces: the design not yet built

Status: **proposal**.

People-pleasing: a face for everyone, to be loved. Ten masks on a ring of stone, turning, one for each of the floor's ten ditches.

## What the design asks

- **Phase 1, Charms.** Each mask copies one projection of this floor.
- **Phase 2, Swaps.** The masks change places; only the one facing away is real.
- **Phase 3, Plain.** The masks fall, and one plain face is left.
- **Release.** The ten masks lie face up and become stepping stones.

## What the build has

One summon of a basic pattern every six seconds, a jump to a point on a ring with a strike, and a ring of force from its body (see [built: The Many Faces](../../built/bosses/MANY-FACES.md)).

## Open questions

- **Count.** Ten masks in the design; six in the model. Which?
- **Copying.** The design copies this floor's projections, not three basic ones. The copies need a rule for which projection a mask shows.
- **Real mask.** The one that is real is either the one facing away, or the one the player's intention meets. Decide the rule before it is built.
