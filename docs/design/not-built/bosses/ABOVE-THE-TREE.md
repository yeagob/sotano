# Above: the Tree's patterns and bosses

Status: idea. The climb up the giant tree is not a fight against the same patterns: it is the subtle ones that come with growing. To be designed with the owner.

As above, so below ([COSMOLOGY](../../../lore/COSMOLOGY.md)): each upper floor mirrors a zone below.

| Floor | Mirror | Patterns (proposal) | Boss (proposal) |
|---|---|---|---|
| L1 Trunk | the Roots | Striving: never high enough | **The Ladder** ([THE-LADDER](THE-LADDER.md)): a climb that keeps adding rungs |
| L2 Branches | the Ledger Halls | Pride, being above others | **The Pedestal** ([THE-PEDESTAL](THE-PEDESTAL.md)): it lifts you up and dares you to look down |
| L3 Leaves | the Frozen Bottom | Attachment, even to the light | **The Last Thing** ([THE-LAST-THING](THE-LAST-THING.md)): what you most want to keep; you release it by letting go of it |

The Tree's floors are described in [built/levels/giant-tree](../../built/levels/giant-tree/README.md) (what is built) and [not-built/levels](../../not-built/levels/README.md) (what is designed). The Tree's bosses are not built; the built bosses are in [built/bosses](../../built/bosses/README.md).
