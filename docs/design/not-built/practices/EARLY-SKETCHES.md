# Early item sketches

Up: [not-built practices](README.md)

Status: idea (superseded: the first design sketches, with provisional names. The built catalogue replaced them; each sketch below is either built under another name or not built).

These sketches were the first brainstorm of passive items on pedestals, written before the catalogue of practices existed. Their names were provisional and original. Each one is listed with what it became.

| Sketch | Effect as first written | Synergy first imagined | Status |
|---|---|---|---|
| Fire intent | Intentions burn | Burns flammable blocks; burning enemies ignite wood | Not built as a practice. Fire is an element ([elements](../../built/elements/README.md)) |
| Drill | Pierces N soft blocks | With fire, a burning tunnel; with explosive, a blast at the end | Not built. Kaizen pierces soft blocks |
| Explosive intent | Explodes on impact, and can hurt you | Very fast digging; dangerous in small rooms | Not built |
| Magnet | Intentions home in on enemies | Home in on the weakest block (an exception to the design) | Not built. Affirmation homes toward blocks |
| Lead feet | You kick blocks very hard | Heavy blocks become lethal projectiles | Not built as this. Grounding doubles the kick |
| Stone heart | +1 heart; the block you carry blocks one hit | An obsidian block as a shield | Not built |
| Mole eye | See the outline of hollows and rooms through rock | Find hidden pockets | Not built. See [META-PROGRESSION](../story/META-PROGRESSION.md) |
| Builder's hands | Carry 2 blocks | Partly solves how to climb | Built as Second Brain |
| Leaden intent | More damage and more drop; they fall like cannonballs | With drill, very fast vertical digging | Partly built as Stoic Resolve (damage and drop) |
| Chain reaction | Breaking a block damages neighbours of the same material | The first sketch compares it to the hockey stick of the Joel gift project | Built as Habit Stacking |

## Weapons

The first design also described the weapons that replace the intention, like a continuous beam or a thrown pickaxe that returns. Two are built: Remember Breathing and Cut Ties with Toxic People ([built practices](../../built/practices/README.md#weapons-that-replace-the-intention)). A thrown pickaxe and a melee drill are not built.
