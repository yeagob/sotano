## Decided design rule

Status: decided (the owner's rule for designing items, from the first design sketches).

Every practice must touch at least two systems: combat and blocks, or blocks and movement, for example. A practice that only changes a number is filler. The built catalogue follows the rule where it can; a check of each practice against it is not recorded.

## Potions

The potions proposal, the alembic and the brewing of captive parts into potions, is in [potions](potions/README.md). It is a proposal, not a decision. It is the candidate answer to [PARTS-PURPOSE](PARTS-PURPOSE.md) and to the shop question in [SHOP](SHOP.md).
