# Questioning Tincture

Status: proposal. The name and numbers are proposals; the brewing caps are approved ([BREWING-RULES](BREWING-RULES.md)). Index: [potions](README.md).

A question that opens a lock. The next lock asks for one key less, and the tincture cannot open the way down.

- **Path:** mind.
- **Bulb contents:** one mind of the Doubt lineage, and one iron ore cube.
- **Effect:** the next lock (a door or a chest) asks one key less, never below zero. It never covers the toll.
- **Duration:** one lock, or the floor, whichever comes first.
- **Why it stays scarce:** one lock per flask. It cannot open the way down.

## Open questions

1. The toll ([LEVELS](../../levels/CAVERN-SCENERY.md) §1c) is never covered. Does a lock that is a toll count as a door for this effect?
2. With the Socratic Questioning practice, the tincture covers two locks ([HOW-IT-FITS](HOW-IT-FITS.md) §4). Confirm that this is the only synergy that changes its count.
3. Key costs are in [CHESTS](../../../built/chests/CHESTS.md). The effect must not contradict the chest's cost table.
