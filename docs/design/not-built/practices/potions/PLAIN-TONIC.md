# Plain Tonic

Status: proposal. The name and numbers are proposals; the brewing caps are approved ([BREWING-RULES](BREWING-RULES.md)). Index: [potions](README.md).

The fallback brew: whatever the bulb holds that no recipe matches. A brew is never nothing, and this is the smallest gift.

- **Path:** body.
- **Bulb contents:** anything no other recipe matches, for example one flesh.
- **Effect:** heals half a heart.
- **Duration:** instant.
- **Why it stays scarce:** it spends a whole brew for the smallest gift.

## Open questions

1. Does an empty bulb brew Plain Tonic, or does the bulb refuse a brew with nothing in it? The proposal says a brew is never nothing, so the default is that it brews.
2. Is a half heart a fixed value or a fraction of the player's maximum health?
