# Spring Tonic

Status: proposal. The name and numbers are proposals; the brewing caps are approved ([BREWING-RULES](BREWING-RULES.md)). Index: [potions](README.md).

One floor of easier climbing. The name refers to the spring of the Impulse pattern.

- **Path:** body.
- **Bulb contents:** one heart of a body pattern, for example Impulse's spring.
- **Effect:** jump strength times 1.4.
- **Duration:** one floor.
- **Why it stays scarce:** hearts drop 5 % of the time. It gives one floor of easier climbing, not the climb back.
