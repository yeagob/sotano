# Patient Draught

Status: proposal. The name and numbers are proposals; the brewing caps are approved ([BREWING-RULES](BREWING-RULES.md)). Index: [potions](README.md).

A draught for digging. It uses two kinds from one pattern, and it helps the player dig, not fight.

- **Path:** will.
- **Bulb contents:** one flesh and one mind of the same will pattern.
- **Effect:** mining times 1.6.
- **Duration:** one floor.
- **Why it stays scarce:** two kinds from one pattern. It helps the player dig, not fight.
