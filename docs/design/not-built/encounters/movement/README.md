# Movement (not built)

Status: **proposal** for the swimmer, the mounted and the burrower; **idea** for the patrol.

The movement classes the design asks for that the build does not have, and the one behaviour that is defined but unused. The built movement behaviours are in [built: Movement](../../../built/encounters/MOVEMENT.md). Each class is a document here, with a status line.

| Document | Class | Projections it serves | Status |
|---|---|---|---|
| [SWIMMER.md](SWIMMER.md) | Lives in liquid and surfaces to attack | Undertow, Sulk (in the design) | proposal |
| [MOUNTED.md](MOUNTED.md) | Fixed to a wall, ceiling or block | The Shoulds, Avoidance (in the design) | proposal |
| [BURROWER.md](BURROWER.md) | Moves through rock along a fixed loop | Rumination (in the design) | proposal |
| [PATROL.md](PATROL.md) | Follows a route of points, defined but unused | Autopilot's loop does this job in its file | idea |

Movement classes are behaviours, not projections. A projection that the design gives a class and that is built with another behaviour is noted in its document, and in the built movement document.
