# Encounters (not built)

Status: **mixed**: proposal for most, decided for the trial room's pedestal. Each document carries its own line.

What the design asks for the fights of the rooms and the built encounter layer does not have: more places for projections to rise from, rooms that wait for the player to trigger them, the Tree's corridor, the compost of parts, the signals of the sound, and the movements that need a body the build does not have. The built rules are in [built/encounters](../../built/encounters/README.md); each document here has a status line.

Two subfolders hold the variants that are read one at a time: [spawn-kinds](spawn-kinds/README.md) (where a projection can rise) and [movement](movement/README.md) (how a being can move).
