# Spawn kinds (not built)

Status: **proposal**. Each document carries its own line.

A spawn kind is the kind of place a projection rises from. The built kind is the floor cell (see [built: Spawns and waves](../../../built/encounters/SPAWNS-AND-WAVES.md)). The design has six more, each with its own way of rising, its own sound and the projections that fit it. Each kind is a document here, with a status line.

| Document | Where it rises | Status |
|---|---|---|
| [WALL.md](WALL.md) | A solid wall block, between head height and the floor | proposal |
| [CEILING.md](CEILING.md) | A ceiling or vault block, dropping down | proposal |
| [LIQUID.md](LIQUID.md) | The surface of water or lava | proposal |
| [ELEMENT-SOURCE.md](ELEMENT-SOURCE.md) | A flame or a brazier | proposal |
| [BLOCK.md](BLOCK.md) | A loose or placed block in the room, which opens eyes | proposal |
| [BURROW.md](BURROW.md) | A crack in the rock around the room, from a burrow | proposal |

Every kind shares the omen: a projection is announced before it exists, at its point, with the same fairness rules (see [Fairness rules](../FAIRNESS-RULES.md)). Templates are to carry the spawn marks: a legend for floor, wall and ceiling (`s`, `w`, `c`) and a role for each point (`any`, `flank`, `high`, `ambush`). The legend is not built.
