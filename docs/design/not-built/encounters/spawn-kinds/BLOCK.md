# Block spawn

Status: **proposal** (design text, bestiary section 2.2).

A loose cube or a placed block in the room trembles and opens eyes: the block is the projection. Its knock is heard from inside.

## What the design asks

- **Rising.** The block trembles and opens eyes; it is the projection.
- **Sound.** A low knock from inside the block, before it opens.
- **Fits.** Avoidance, which hides inside a block; Procrastination's crates.

## Open questions

- **Placed blocks.** A block the player placed can become a projection. Decide whether that is fair: the player's own block should not be able to hurt them without warning.
- **Crates.** Procrastination's crates are a stack of blocks; the stack is the projection. The build's Procrastination does not use this.
- **Avoidance.** Avoidance hides out of sight with no host block yet (see [built: encounters](../../../built/encounters/README.md)).
