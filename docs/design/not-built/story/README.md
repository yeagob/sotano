# Story (not built)

Up: [not-built design](../README.md)

The open questions of the story, and the ideas that are not in the code: how the run ends and what is at the top of the tree, who the player is, whether the game links to mental-health resources, and what carries from one run to the next. The story as built is in [built/story](../../built/story/README.md).

Every document here is undecided or an idea. The owner decides the open ones; the design does not decide them silently.

| Document | Status | Contents |
|---|---|---|
| [ENDGAME.md](ENDGAME.md) | Status: open question | How the run ends, what the bottom and the top connect to, and the place or event of the endgame |
| [THE-SKY-MEANING.md](THE-SKY-MEANING.md) | Status: open question | What the sky above the tree means, and how silence connects with heaven |
| [PROTAGONIST.md](PROTAGONIST.md) | Status: open question (story question 1) | Who the player is, and whether the person is ever shown |
| [MENTAL-HEALTH-LINK.md](MENTAL-HEALTH-LINK.md) | Status: open question (story question 4) | Whether the game links to real mental-health resources, and how |
| [META-PROGRESSION.md](META-PROGRESSION.md) | Status: idea (story question 3) | What a run leaves for the next one, and the hidden pockets and side biomes |

The owner's decisions on the thirteen floors are in the levels documents, and the cosmology these questions rest on is in [COSMOLOGY](../../../lore/COSMOLOGY.md).
