# Elements (not built)

Up: [not-built](../README.md) · the element ideas and proposals that the code does not have yet.

This folder holds the matter and fire the owner has asked for and the design has described, but that no code runs: mud, sand, glass, electricity, furnaces, burning barrels, the burning status of actors and cubes, and the changes that depend on them (grass that burns, deepstone that melts, dirt that turns to mud, chests you can put things in or break). Each one is a document with its status line, the verbs it would give the player, the elements or materials it reacts with, and its open questions. Built elements are in [built/elements](../../built/elements/README.md); when one is built its text moves there.

Status lines use the three words of the design tree: `decided` (the owner decided it), `proposal` (designed, awaiting a build or the owner), `idea` (a brainstorm with no commitment). Open questions are listed where they are; none is settled by a build without a note.
