# Practices that change elements

Up: [not-built elements](README.md) · Status: idea.

The design gives seven practices that would change how the player meets the elements: breathwork, swimming lessons, fire walking, cold exposure, alchemy, insight and grounding. None is built as an element practice. Two names exist in the item catalogue with other effects, so the names are not free to reuse as they are.

## The seven ideas

| Practice (design) | What it would do to the elements | Built today |
|---|---|---|
| Breathwork | Longer breath under water | No. The breath is 8 seconds for everyone |
| Swimming lessons | "Flow" variants of swimming: move better in water | No. The item called Flow raises movement speed and fire rate, not swimming |
| Fire walking | Immune to fire | No. Fire hurts everyone |
| Cold exposure | Extinguishes what the player touches | No |
| Alchemy | Better furnace results | No furnace exists |
| Insight | Electric intentions (a charge from the player's shot) | No electricity exists |
| Grounding | Immune to shocks | No electricity exists. The item called Grounding doubles kick strength instead |

The practice Kindling is built and does touch fire: when a projection hurts the player, fire bursts out of the player, and flammable blocks within two blocks catch. It is not one of the seven.

## Open questions

1. Should the practice names of the seven be reused for element effects, or should the element effects take new names (the owner names practices from public-domain works or generic techniques)?
2. Which of the seven is worth a practice, given that the furnace, electricity and fire immunity are not yet built?
3. Does Breathwork change the breath meter, or add a second meter?
