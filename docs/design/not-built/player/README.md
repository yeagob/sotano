# The player (not built)

What the player could do or have that the game does not do yet: movement beyond walking and jumping, climbing, more kinds of hearts, falls that hurt, a shop, and a second life after death. Each document starts with its status line. Nothing here is true in the code; what is built is in [built/player](../../built/player/README.md).

## Open questions shared by the folder

1. **Camera.** The first-person camera is built and the design asks for it ([DESIGN.md, section 13, question 6](../README.md)). The design also suggests prototyping a steeper, top-down camera, closer to Isaac and easier to read on a phone, before the first person is locked in. Should the owner prototype it, or keep the first person as decided?
