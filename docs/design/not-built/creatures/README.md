# Creatures (not built)

Status: **proposal**. Each document carries its own line.

The creatures in the game are built and documented in [built/creatures](../../built/creatures/README.md): they wander, flee, chirp and rest. The design asks for more: they dig, carry, clean, thaw, befriend and show the way. Each of these is a document here, with a status line. The creatures' shared rules (neutral, never killed, hidden on seal, polarity) are built and are not repeated here.

| Document | What is not built | Creatures | Status |
|---|---|---|---|
| [BEFRIENDING.md](BEFRIENDING.md) | Gentle acts that make a creature follow the player for a floor | Delver, Huddler, others | proposal |
| [BURROWING.md](BURROWING.md) | Tunnels, secret pockets and digging a block ahead | Rootling, Delver | proposal |
| [WATER-AND-FERRY.md](WATER-AND-FERRY.md) | Bubbles that refill breath, and a creature to stand on for crossing | Bubbler, Ferryback | proposal |
| [UPDRAFTS.md](UPDRAFTS.md) | Rides up in tall rooms, and jumping on a creature as a platform | Drifter | proposal |
| [CLEANING.md](CLEANING.md) | Eating the judgement marks off the floor during fights | Inkmite | proposal |
| [THAWING.md](THAWING.md) | Thawing the ice of the frozen floor, and the frost's slow | Huddler | proposal |
| [CROSSING-FIRE.md](CROSSING-FIRE.md) | A path of cooled stone behind a creature crossing lava | Cinderwalker | proposal |
| [TELEPORT-DOORS.md](TELEPORT-DOORS.md) | Pointing out and joining the teleport doors on the star map | Leafling, Star-mite | proposal |

The design's chirping rule (silence near projections, including ambushes) is partly built and is recorded in the Chirper's document.
