# Crossing fire

Status: **proposal** (design text, bestiary section 7.2).

Cinderwalkers walk across lava. Behind them the lava cools to stone for a few seconds, so the path they walked is a path the player can follow across lava, quickly.

## What the design asks

- **Cooling path.** The lava a Cinderwalker leaves cools to stone for a few seconds.
- **Following.** The player can follow the cooled path across the lava.

## What the build has

Cinderwalkers cross lava and fire without harm. The lava does not cool behind them.

## Open questions

- **Material.** Cooled stone is a new state of the lava. It needs the elements design (ELEMENTS) and an art ruling.
- **Timing.** A few seconds is short. Decide the path's length and how the player sees it fade.
- **Hazard.** A path that cools must never trap the player in lava when it fades. The rule must be safe before it is built.
